얼마 - 데이터 삭제 안내

'얼마'는 개인 예산과 지출을 관리하는 앱입니다. 별도의 회원가입이나 로그인 없이 사용할 수 있습니다.

1. 앱에서 데이터 삭제하기

다음 방법으로 저장된 가계부 데이터를 삭제할 수 있습니다.

  1. '얼마' 앱을 실행합니다.
  2. 설정 화면으로 이동합니다.
  3. '데이터 초기화' 버튼을 선택합니다.
  4. 초기화를 진행하면 기기에 저장된 앱 데이터가 삭제됩니다.

2. 삭제되는 데이터

데이터 초기화 시 다음과 같은 기기 내 저장 정보가 삭제됩니다.

  • 월 예산 및 수입 정보
  • 지출 내역 및 지출 카테고리
  • 저축 및 투자 계획
  • 기타 앱에 저장한 설정 정보
데이터 초기화 후에는 삭제된 정보를 앱에서 복구할 수 없습니다.

3. 데이터 삭제 문의 및 요청

앱 내에서 데이터를 삭제하기 어렵거나 데이터 처리와 관련하여 문의하려면 아래 이메일로 연락해 주세요.

이메일: ge323.dev@gmail.com

문의 시 '얼마 앱 데이터 삭제 요청'이라는 제목으로 연락해 주세요. 삭제 가능한 데이터의 범위와 처리 방법을 안내해 드립니다.

4. 광고 관련 데이터

앱에는 Google AdMob 광고 서비스가 포함될 수 있습니다. 광고 서비스에서 처리하는 정보는 Google의 개인정보처리방침에 따라 관리됩니다. 앱 내 데이터 초기화가 Google의 광고 관련 데이터까지 삭제하는 것은 아닙니다.

5. 데이터 보관

가계부 정보는 기본적으로 사용자 기기에 저장됩니다. 개발자가 별도의 서버에 가계부 정보를 보관하지 않으므로, 개발자가 원격으로 해당 기기 내 정보를 직접 삭제할 수는 없습니다.
